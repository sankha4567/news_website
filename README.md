Modern News Website
A responsive and user-friendly news website built using HTML, CSS, and JavaScript. This platform fetches the latest news from an API, keeping users updated with recent events worldwide.

Features
✅ Fetches real-time news using an API
✅ Responsive design for all devices
✅ Category-based news filtering
✅ Search functionality for specific topics

Tech Stack
Frontend: HTML, CSS, JavaScript
API: News API for fetching the latest news

Installation & Setup
1) Clone the repository:git clone https://github.com/your-username/news-website.git
2)cd news-website
3)Open index.html in your browser or use a live server extension for better experience.
